# OperationsRelated

Operations, HR and field-work apps, one folder each. See each folder's README for setup and build steps.

| Folder | App |
|---|---|
| `MileageClaim/` + `MileageAdmin/` + `mileage-backend/` | Staff mileage claims, admin viewer, Google Sheets backend |
| `hr-connect-app/` | HR department app with WiFi/GPS auto clock-in |
| `SubConTracker/` | Sub-contractor daily work-day log |
| `WIPStatusTracker/` | Pending work-in-progress job tracker |
| `HappyRepairApp/` | Signed Android wrappers of Workshop Manager |
| `IDCapture/` | IC / passport photo capture in a guide box |
| `PhotoBrander/` | Photo to AI-branded marketing image via n8n |
| `VehicleRecords/` | Fleet records for cars, motorcycles and vans |
| `TripLogger/` | Trip logging with auto date/time to Google Sheets |
| `IdeaCapture/` | Quick idea notes tagged by urgency |

Built APKs are published under **Releases**, not committed to the repo.
