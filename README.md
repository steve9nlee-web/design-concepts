# Design Concepts

Prototypes, concept pages and early-stage app builds, one folder each. See each folder's README for setup and build steps.

## Concept pages
| Folder | What it is |
|---|---|
| `3d-property/` | 3D scroll-descent front page for a property agency (single HTML file) |
| `scifi-login/` | "Quantum Access Node" sci-fi HUD login concept |
