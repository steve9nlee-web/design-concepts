# PersonalApps

Personal-use apps, one folder each. See each folder's README for setup and build steps.

| Folder | App |
|---|---|
| `CalorieCam/` | Daily food calorie tracking from photos |
| `FitTrainer/` | Age-adapted guided exercise training with timers |
| `RouteTracker/` + `RouteTrackerPro/` | GPS route recorder; Pro adds tile map and Excel sync |
| `ScamCallGuard/` | Scam call identifier and blocker |
| `info-keeper/` + `sa-vault-android/` | Passphrase-protected personal info vault (web + Android) |
| `world-monitor/` | Local-first OSINT dashboard with 3D globe |

Built APKs are published under **Releases**, not committed to the repo.
