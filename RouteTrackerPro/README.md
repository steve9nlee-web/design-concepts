# RouteTracker Pro

Android app that automatically records the route you travel using GPS, with
your home WiFi network acting as the start/stop trigger — plus a **real map
view with OpenStreetMap tiles** and an **Excel trip log kept in Google
Drive**.

## How it works

1. Connect your phone to your home WiFi, open the app, and tap
   **"Use current WiFi as home"** to designate it.
2. Enable **"Auto-track when I leave home WiFi"**. A persistent notification
   shows that monitoring is active.
3. The moment your phone **disconnects from the home WiFi**, GPS route
   recording starts automatically.
4. When your phone **reconnects to the home WiFi**, recording stops, the trip
   is saved — and the Excel log in Google Drive is updated automatically
   (you're back on WiFi at that moment, so it syncs right away).

## Map view

Trip details show the route on a real, pannable/zoomable street map
(OpenStreetMap tiles via osmdroid — no API key needed). Green marker =
departure, red = return, orange = stops; tap a stop marker to see arrival
time and how long you stayed.

## Excel log in Google Drive

Tap **"Choose Excel file in Drive"** once: in the system picker, open the
menu (☰), select **Drive**, pick a folder, and save `RouteTracker
TripLog.xlsx`. From then on the app rewrites that file after every completed
trip (and on demand with **"Update Excel now"**). No Google Cloud setup, no
API keys — the file is written straight through the Google Drive storage
provider and synced by the Drive app.

The workbook has two sheets:

- **Trips** — Date, Left home, Returned, Duration (min), Distance (km), Stops
- **Stops** — per stop: arrival, departure, minutes stayed, coordinates, and
  a Google Maps link

The .xlsx is generated by the app itself (pure Office Open XML, no
libraries) and opens in Excel, Google Sheets, and LibreOffice.

## Install

Sideload `apk/RouteTrackerPro-v1.0.apk` (Android 8.0+). It installs
alongside the original RouteTracker as a separate app.

1. Allow "install unknown apps", open the APK.
2. Grant **Location → Allow all the time** when arming monitoring.
3. Keep Location (GPS) on — Android requires it to read WiFi names.
4. Recommended: exclude the app from battery optimisation.
5. The Google Drive app must be installed and signed in for the Drive
   option to appear in the file picker.

> **Note on the "1 m" trigger:** WiFi cannot geofence to 1 metre — the app
> starts recording the instant the home WiFi connection is lost and stops
> the instant it returns, with debouncing (25 s / 10 s) against flaky
> connections.

## Privacy

Trip data lives in a local SQLite database. Network access is used for two
things only: fetching map tiles from OpenStreetMap when you open a trip, and
writing the Excel file to the Google Drive location **you** picked. Nothing
else leaves the device. Long-press a trip to delete it.

## Build from source

```bash
cd RouteTrackerPro
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Requires JDK 17+ and the Android SDK (platform 35, build-tools 34+).
